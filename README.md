💻 Mini Project: Real-Time Todo Management System

🚀 Project Overview
This is a practical and professional mini project where you will build a real-time styled Todo Management System using Node.js, Express.js, and EJS with simple array/object storage.
The goal is to create a system that feels like a real productivity app — combining a clean UI with solid backend logic 🔥

🎯 Objective
In this project, users can:
➕ Add tasks
📊 Track progress
✏️ Edit tasks
❌ Delete tasks

👉 The main focus is on real-world backend flow + professional UI structure

🧩 Core Modules Breakdown

📊 1. Dashboard Module
The dashboard acts as the main control center of the application
✨ It includes:

📌 Navbar
📈 Task statistics cards (Total, Pending, Completed)
📋 Task table
➕ Add Task button

👉 Users can instantly view task summaries

➕ 2. Task Creation Module
Users can create a new task with:

📝 Title
📄 Description
⚡ Priority

⚙️ Logic:

Accept form data
Generate a unique task ID
Store it in an array/object

👉 The new task appears immediately in the list

📋 3. Task Listing Module
Displays all tasks in a structured table

📌 Fields:

ID
Title
Description
Priority
Status
Actions

⚡ Actions include:
✏️ Edit
❌ Delete
🔄 Status Change

👉 Built with a responsive Bootstrap table

✏️ 4. Task Update Module
Users can update existing tasks

⚙️ Logic:

Open edit page using task ID
Load previous values
Update task object

👉 Changes reflect instantly on the dashboard

❌ 5. Task Delete Module
Users can remove tasks easily

⚙️ Logic:

Select task by ID
Remove from array

👉 Task disappears immediately from the UI

🔄 6. Task Status Management Module
Tasks follow a structured flow:
🟡 Pending → 🔵 In Progress → 🟢 Completed

👉 Progress updates dynamically
